# Environment Setup Generator

This skill generates environment configuration files and developer onboarding scripts for a project.

## Usage

Run `/env-setup <stack>` where stack is: `laravel`, `node`, `angular`, `fullstack`

## Structure

Generates:
- `.env.example`: Documented environment template with all required variables
- `Makefile`: Common development commands (setup, dev, test, lint, build, deploy)
- `scripts/setup.sh`: First-time setup script for new developers
- `.editorconfig`: Consistent editor settings
- `.nvmrc` or `.php-version`: Runtime version pinning

## Standards

- **Never commit secrets**: .env must be in .gitignore, .env.example has placeholders only
- **Document every variable**: Each env var has a comment explaining its purpose
- **Group variables**: Organize by category (App, Database, Cache, Mail, Services, etc.)
- **Sensible defaults**: Development defaults that work out of the box
- **Makefile targets**: PHONY targets with help descriptions
- **Setup idempotency**: Running setup.sh twice should be safe

## Process

1. **Detect project**: Read existing config files to understand the stack
2. **Generate .env.example**: With all needed variables, grouped and documented
3. **Generate Makefile**: With targets for the detected stack
4. **Generate setup script**: That installs deps, copies .env, runs migrations, etc.
5. **Generate .editorconfig**: Matching project conventions

## Examples

### 1. Laravel .env.example

```env
###############################################################################
# Application
###############################################################################

# The name of your application (used in notifications, page titles, etc.)
APP_NAME="My Application"

# Application environment: local, staging, production
APP_ENV=local

APP_URL=http://localhost

LOG_CHANNEL=stack

# Log deprecation warnings (channel: null to disable)
LOG_DEPRECATIONS_CHANNEL=null

LOG_LEVEL=debug

###############################################################################

# Database driver: mysql, pgsql, sqlite, sqlsrv
DB_CONNECTION=mysql

DB_PASSWORD=
```

### 2. Makefile (Laravel + Docker)

```makefile
.DEFAULT_GOAL := help

# Container name used across targets
DOCKER_COMPOSE = docker compose
EXEC_PHP = $(DOCKER_COMPOSE) exec app
EXEC_NODE = $(DOCKER_COMPOSE) exec node

##@ Setup

.PHONY: setup
setup: ## First-time project setup (copies env, builds containers, installs deps, runs migrations)
	@bash scripts/setup.sh

##@ Docker

.PHONY: up
up: ## Start all Docker containers in the background
	$(DOCKER_COMPOSE) up -d

.PHONY: down
down: ## Stop and remove all Docker containers
	$(DOCKER_COMPOSE) down

.PHONY: build
build: ## Build or rebuild Docker images
	$(DOCKER_COMPOSE) build

.PHONY: logs
logs: ## Tail logs from all containers (Ctrl+C to stop)
	$(DOCKER_COMPOSE) logs -f

.PHONY: shell
shell: ## Open a bash shell inside the PHP container
	$(EXEC_PHP) bash

.PHONY: restart
restart: down up ## Restart all containers

##@ Laravel

.PHONY: migrate
migrate: ## Run database migrations
	$(EXEC_PHP) php artisan migrate

.PHONY: seed
seed: ## Run database seeders
	$(EXEC_PHP) php artisan db:seed

.PHONY: fresh
fresh: ## Drop all tables, re-run migrations, and seed the database
	$(EXEC_PHP) php artisan migrate:fresh --seed

.PHONY: tinker
tinker: ## Open Laravel Tinker REPL
	$(EXEC_PHP) php artisan tinker

.PHONY: cache-clear
cache-clear: ## Clear all Laravel caches (config, route, view, app)
	$(EXEC_PHP) php artisan optimize:clear

.PHONY: queue
queue: ## Start the queue worker
	$(EXEC_PHP) php artisan queue:work

##@ Testing & Quality

.PHONY: test
test: ## Run the full test suite
	$(EXEC_PHP) php artisan test

.PHONY: test-coverage
test-coverage: ## Run tests with code coverage report
	$(EXEC_PHP) php artisan test --coverage

.PHONY: lint
lint: ## Run Laravel Pint code style fixer
	$(EXEC_PHP) ./vendor/bin/pint

.PHONY: lint-check
lint-check: ## Check code style without fixing (CI-friendly)
	$(EXEC_PHP) ./vendor/bin/pint --test

.PHONY: analyse
analyse: ## Run PHPStan static analysis
	$(EXEC_PHP) ./vendor/bin/phpstan analyse

.PHONY: ci
ci: lint-check analyse test ## Run the full CI pipeline locally (lint + analyse + test)

##@ Frontend

.PHONY: npm-install
npm-install: ## Install Node.js dependencies
	$(EXEC_NODE) npm install

.PHONY: dev
dev: ## Start Vite dev server with HMR
	$(EXEC_NODE) npm run dev

.PHONY: build-assets
build-assets: ## Build frontend assets for production
	$(EXEC_NODE) npm run build

##@ Help

.PHONY: help
help: ## Show this help message
	@awk 'BEGIN {FS = ":.*##"; printf "\nUsage:\n  make \033[36m<target>\033[0m\n"} /^[a-zA-Z_-]+:.*?##/ { printf "  \033[36m%-18s\033[0m %s\n", $$1, $$2 } /^##@/ { printf "\n\033[1m%s\033[0m\n", substr($$0, 5) }' $(MAKEFILE_LIST)
```

### 3. setup.sh (Laravel + Docker)

```bash
#!/usr/bin/env bash
set -euo pipefail

# ---------------------------------------------------------------------------
# Colors
# ---------------------------------------------------------------------------
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
NC='\033[0m' # No Color

info()    { printf "${BLUE}[INFO]${NC}  %s\n" "$1"; }
success() { printf "${GREEN}[OK]${NC}    %s\n" "$1"; }
warn()    { printf "${YELLOW}[WARN]${NC}  %s\n" "$1"; }
error()   { printf "${RED}[ERROR]${NC} %s\n" "$1"; exit 1; }

# ---------------------------------------------------------------------------
# Require tools
# ---------------------------------------------------------------------------
info "Checking required tools..."

command -v docker  >/dev/null 2>&1 || error "docker is not installed. Visit https://docs.docker.com/get-docker/"
command -v docker  compose version >/dev/null 2>&1 || error "docker compose (v2) is required. Update Docker Desktop or install the compose plugin."
command -v composer >/dev/null 2>&1 || warn "composer not found locally (will use the container instead)"
command -v node    >/dev/null 2>&1 || warn "node not found locally (will use the container instead)"

success "Required tools are available."

# ---------------------------------------------------------------------------
# Environment file
# ---------------------------------------------------------------------------
if [ ! -f .env ]; then
    info "Copying .env.example to .env..."
    cp .env.example .env
    success ".env file created."
else
    warn ".env already exists, skipping copy."
fi

# ---------------------------------------------------------------------------
# Composer dependencies
# ---------------------------------------------------------------------------
info "Installing Composer dependencies..."
if command -v composer >/dev/null 2>&1; then
    composer install --no-interaction --prefer-dist
else
    docker compose run --rm app composer install --no-interaction --prefer-dist
fi
success "Composer dependencies installed."

# ---------------------------------------------------------------------------
# Start containers
# ---------------------------------------------------------------------------
info "Starting Docker containers..."
docker compose up -d --build
success "Containers are running."

# ---------------------------------------------------------------------------
# Wait for MySQL
# ---------------------------------------------------------------------------
info "Waiting for MySQL to be ready..."
MAX_TRIES=30
COUNT=0
until docker compose exec db mysqladmin ping -h 127.0.0.1 --silent 2>/dev/null; do
    COUNT=$((COUNT + 1))
    if [ "$COUNT" -ge "$MAX_TRIES" ]; then
        error "MySQL did not become ready in time (${MAX_TRIES}s)."
    fi
    sleep 1
done
success "MySQL is ready."

# ---------------------------------------------------------------------------
# Application key
# ---------------------------------------------------------------------------
if grep -q "^APP_KEY=$" .env 2>/dev/null; then
    info "Generating application key..."
    docker compose exec app php artisan key:generate
    success "Application key generated."
else
    warn "APP_KEY already set, skipping generation."
fi

# ---------------------------------------------------------------------------
# Migrations & seed
# ---------------------------------------------------------------------------
info "Running database migrations..."
docker compose exec app php artisan migrate --force
success "Migrations complete."

info "Seeding the database..."
docker compose exec app php artisan db:seed --force
success "Database seeded."

# ---------------------------------------------------------------------------
# Node dependencies
# ---------------------------------------------------------------------------
info "Installing Node.js dependencies..."
if command -v node >/dev/null 2>&1; then
    npm install
else
    docker compose run --rm node npm install
fi
success "Node.js dependencies installed."

# ---------------------------------------------------------------------------
# Done
# ---------------------------------------------------------------------------
printf "\n${GREEN}============================================${NC}\n"
printf "${GREEN}  Setup complete!${NC}\n"
printf "${GREEN}============================================${NC}\n\n"
info "Next steps:"
echo "  1. Review your .env file and adjust any values"
echo "  2. Run 'make dev'   to start the Vite dev server"
echo "  3. Run 'make test'  to verify everything works"
echo "  4. Visit http://localhost in your browser"
echo ""
```
