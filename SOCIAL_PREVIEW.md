# Social Preview Image Recommendations

## GitHub Repository Social Preview

Recommended size: **1280×640px** (2:1 ratio)

### Design Suggestions

**Option 1: Modern Tech Style**
- Dark gradient background (#0d1117 to #161b22)
- Central animated robot/agent icon
- Text: "80+ AI Agents" in bold, modern font
- Subtext: "Supercharge Your Development Workflow"
- Accent color: Green (#238636) or Purple (#8957e5)

**Option 2: Workflow Diagram Style**
- Light background
- Visual flow diagram showing agent workflow
- Icons representing different agent categories
- Clean, minimalist design

**Option 3: Code + Agents**
- Split design: Left side code snippet, right side agent icons
- Shows the connection between code and AI assistance
- Syntax highlighting colors

### Tools to Create
- Canva (templates available)
- Figma (free)
- Adobe Express
- GitHub Social Preview Generator

### Text to Include
- Main: "AI Coding Agents"
- Sub: "80+ Specialized AI Agents"
- Optional tagline: "Your Complete AI Development Team"

## Setting in GitHub

1. Go to repository Settings → General
2. Scroll to "Social Preview"
3. Upload image (1280×640px)
4. Click "Save changes"
